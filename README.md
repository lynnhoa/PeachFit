# PeachFit

Personal progressive overload gym tracker. React + TypeScript + Vite. All data in localStorage — no backend, no account.

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Push repo to GitHub
2. Import in Vercel — framework preset: **Vite**
3. Deploy — no env vars needed

## Add to iPhone home screen
Open in Safari → Share → Add to Home Screen
