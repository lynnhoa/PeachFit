# Exercise photos

A photo here replaces the drawing at the top of an exercise's How-to sheet. Name the file after the
movement (`.jpg`, `.png` or `.webp`, portrait 4:5, 800 × 1000 — all photos the same size) and it shows on
every day that has that exercise — no code change. Movements without a photo keep their drawing. The list
lives in `photos.ts` (`MOVEMENT`); `SAME_AS` lets a movement reuse another's photo; a credit can go in `CREDIT`.

All 27 photos are one set made with Gemini: the same woman, same studio, one photo per movement.
