# Exercise photos

A photo here replaces the drawing at the top of an exercise's How-to sheet. Name the file after the
movement (`.jpg`, `.png` or `.webp`, landscape 3:2, about 1200 × 800) and it shows on every day that has
that exercise — no code change. Movements without a photo keep their drawing. The list lives in
`photos.ts` (`MOVEMENT`); a photographer credit can be added there too (`CREDIT`).
